# AWS Guardian 🛡️
> "You run your servers. We watch them."

AWS Guardian is an intelligent, proactive EC2 instance watchdog. It pairs a deterministic safety rules engine with an AI reasoning layer to catch forgotten or idle workloads and prevent runaway cloud costs.

## Architecture
- **Backend:** Python / FastAPI / SQLAlchemy / Boto3
- **Frontend:** React / Vite / Tailwind CSS
- **CI/CD:** GitHub Actions / Jenkins
- **Deployment Target:** AWS EC2
